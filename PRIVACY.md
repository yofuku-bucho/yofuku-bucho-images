# Privacy Policy — Yofuku Bucho Uploader

Last updated: 2026-11-23

"Yofuku Bucho Uploader" is a private, internal tool used only by the owner of the YouTube channel **洋服部長 (Yofuku Bucho)**: https://www.youtube.com/@yofuku_bucho

## Use of YouTube API Services

This tool uses the **YouTube API Services** (YouTube Data API v3). By using this tool, you agree to be bound by the **YouTube Terms of Service**: https://www.youtube.com/t/terms

Your information is also handled under the **Google Privacy Policy**: http://www.google.com/policies/privacy

## What data is accessed

- Only the channel owner's own YouTube channel, through Google OAuth 2.0 (scope: `youtube.upload`).
- The tool uploads videos made by the channel owner and sets their titles, descriptions and publish times.
- It does not access any other user's account, and it does not read viewer data, comments or analytics.

## What data is collected, stored or shared

- No personal data of viewers or other users is collected, stored, sold or shared.
- The only stored item is the OAuth token for the owner's channel. It is kept privately on the owner's server and used only for the uploads above.

## How to revoke access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions

## Data deletion

When access is revoked, or on request through the channel, the stored OAuth token and any related data are deleted within 7 days.
