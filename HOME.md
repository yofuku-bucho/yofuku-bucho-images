# Yofuku Bucho Uploader

An internal upload tool for the YouTube channel **洋服部長 (Yofuku Bucho)**.

▶ YouTube channel: https://www.youtube.com/@yofuku_bucho

The channel explains apparel retail and clothing knowledge in short videos. This tool uses the **YouTube API Services** (YouTube Data API v3) only to upload the owner's own videos to the owner's own YouTube channel and to set their titles, descriptions and publish times. It is used only by the channel owner.
